# hub-plugin-projects-status

<img src="icon.png" width="256" alt="Статус проектов">

Плагин страницы Agents Hub «Статус проектов»: все проекты из `hub projects` - что ждёт ответа владельца, что идёт
(этап, бэклог направления), что готово, что без направления. Карточка проекта - его память: этап, цель, «что дальше»,
ключевые решения и история правок с автором. Вкладка «Задачи» - доска проекта: новая задача (тип, приоритет,
исполнитель - сессия или сам владелец, срок), статус меняется перетаскиванием. Задачи - файлы Backlog.md: бэклог
одного из живых направлений проекта или свой бэклог `<state>/projects-memory/<проект>/backlog` (поле «Куда»).

У проекта может быть несколько направлений: все, чьё репо - папка проекта (или внутри неё), и привязанные вручную
(направление с другим репо, например Android-версия: «Привязать направление» в карточке или `pmem.py set <проект> --link
<направление>`). Поле «Написать проекту» в карточке и «Написать по проектам» на главной - как чат Хаба: сообщение уходит
Хабу с контекстом проекта (папка, направления и кто их ведёт), и он решает, кому его отдать - ведущему направления,
агенту или задачей.
Задачи без проекта (кнопка «Новая задача», проект «Без проекта») - в общем бэклоге
`<state>/projects-memory/_general/backlog`. Задачи владельца стоят в «Ждёт вас».

- `main.py` - процесс плагина: сворачивает правки памяти из канала плагина (`hub post projects-status '<json>'`) в
  `<state>/projects-memory/memory.json` и `<проект>.md`, отдаёт данные странице на порту «порт страницы + 12».
- `pmem.py` - для сессий: `pmem.py show [<проект>]`, `pmem.py set <проект> --stage … --note … --goal … --add … --done …`,
  `pmem.py set <проект> --link|--unlink <направление>`, `pmem.py task list|new|status <проект> … [--direction <направление>]`
  (проект `-` - без проекта).
- `web/` - вид страницы (API плагинов `^1.7`).

Подключение - строка в `extensions` настроек хаба:

```json
"projects-status": {"path": "<папка плагина>", "run": ["python3", "main.py"], "web": "web/main.js", "hub": "^1.7"}
```

Тесты: `PYTHONPATH=<код хаба> python3 -m unittest discover -s tests`.
